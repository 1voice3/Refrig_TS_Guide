Refrigerant Troubleshooting mobile app
- Open index.html in a browser.
- Designed for phone use.
- Stores the active service record in the browser's local storage.
- Supports up to 10 snapshots, matching the Excel workbook.
- Preserves workbook calculations: blower average/%FLA, cooling delta-T, superheat, subcool, compressor average/%RLA, absolute pressures, compression ratio, condenser outlet average and delta-T.
- Adds configurable warning thresholds requested by the technician.
- Adds snapshot-to-snapshot difference display.
- Adds troubleshooting pattern clues and a fan-cycling warning.
- Export creates a JSON service record; Print/Save PDF can be used for a paper/PDF record.
